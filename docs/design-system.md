# Punchin 디자인 시스템

## 방향

작은 회사에서 매일 사용하는 업무 도구: 차분한 중립색, 짙은 숲색, 작은 팀에 필요한 정보 밀도.
사이드바와 헤더는 가볍게 두고 오늘 근무 카드를 우선 배치합니다. 실근무·출퇴근 시각은 숫자 폭을 고정합니다. 상태는 색과 텍스트를 함께 사용합니다.

## 토큰과 공통 컴포넌트

`packages/ui/src/styles.css`가 Tailwind 4 테마·색·라운드·버튼·카드·배지·아바타를 소유합니다. 앱별 배치와 화면 전용 스타일은 `packages/app/src/styles.css`에 둡니다.

| 항목    | 기준                                                |
| ------- | --------------------------------------------------- |
| Canvas  | `#f7f8f5`                                           |
| Surface | 흰색                                                |
| Primary | `#244d3d`                                           |
| Accent  | 연한 세이지·라임 계열                               |
| Status  | 근무·승인 녹색 / 대기 황토색 / 휴가 파랑            |
| Card    | 14px 기본 라운드, 얇은 테두리                       |
| Spacing | 4px 기반, 카드 간격 16~22px                         |
| Layout  | 230px 데스크톱 사이드바, 중앙 업무 영역 + 보조 패널 |
| Mobile  | 580px 이하 하단 탐색, 한 열 배치, safe-area 대응    |

Button: primary / secondary / ghost / danger. 네이티브 버튼의 disabled·focus 상태를 유지합니다. Card는 section, Badge는 상태 표시이며 클릭 요소로 사용하지 않습니다. Avatar는 가상 이름의 보조 표식이므로 접근성 트리에서 제외합니다.

## 인터랙션

- 요청 등록은 네이티브 `<dialog>` 사용: 초점 관리, Escape 닫기, 배경 클릭 닫기.
- 날짜·시간 입력은 기기 기본 입력을 활용합니다.
- 토스트는 `role=status`, 오류는 `role=alert`로 알립니다.
- 키보드 focus-visible과 reduced-motion을 지원합니다.
- 모바일 폼 본문은 16px로 입력 시 불필요한 확대를 줄입니다.
- 퇴근 버튼은 8시간 미만에도 동작하고, 확인 대화상자에서 부족 시간을 안내합니다.

브라우저의 작은 화면 검증과 실제 VoiceOver·TalkBack·터치 검증은 다릅니다. 출시 전 실제 기기 접근성, 대비, 큰 글자 설정과 주요 터치 영역을 추가 검증해야 합니다.
