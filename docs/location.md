# 휴데이터스 사무실과 GPS 인증

등록 주소: 서울 금천구 가산디지털2로 83 한진물류터미널 사무동 7F 휴데이터스.

## 좌표 설정

주소와 실제 출퇴근을 기록할 사무동 출입 위치는 다를 수 있으므로 좌표를 추정해 자동 활성화하지 않았습니다. 현재 중심 좌표는 미설정이고 GPS 정책은 꺼져 있습니다. 반경 150m는 시험용 기본값입니다.

관리자는 실제 사무실에서 ‘설정 → 사무실 위치 인증’으로 이동합니다. 현재 위치를 후보로 측정하거나 지도에서 확인한 위도·경도를 입력하고, 50~500m 범위에서 반경을 조정합니다. 실제 좌표·반경을 확인했다는 체크와 GPS 사용 체크 후 저장해야 활성화됩니다. 측정은 HTTPS 또는 localhost와 사용자 위치 권한이 필요합니다. 클라우드 개발 환경의 위치를 실제 사무실 좌표로 쓰지 마세요.

GPS로 7층 출입 여부는 판단하지 않습니다. 직원이 실제로 사용하는 사무실 내부·엘리베이터·건물 출입구에서 Android와 iPhone을 모두 시험하고 실패율을 기록하세요. 넓은 물류터미널의 건물 중심과 사무동 중심을 혼동하지 않아야 합니다.

## 판정

출퇴근 버튼 클릭 때만 위치를 측정합니다. 서버는 활성 정책에 따라 측정 시각의 신선도(60초 이내, 미래 오차 5초 이내), 정확도(100m 이하), 중심까지 거리와 반경을 검증합니다. 오차를 포함해 반경 내부임을 확인할 때 통과하며 경계가 불명확하면 재측정·정정을 안내합니다.

권한 거부·위치 시간 초과·낮은 정확도·범위 밖에서는 성공으로 표시하지 않습니다. 사전 승인된 외근일은 위치 예외로 기록합니다. 급한 외근은 신청·승인 후 출퇴근하거나 기록 정정으로 보완합니다. 현재 외근은 일 단위이고 세밀한 시간 구간은 후속 정책입니다.

개인 정밀 좌표는 DB에 저장하지 않습니다. 원본 이벤트에는 판정 종류, 근무지 설정 버전, 거리·오차 정도만 남깁니다. 상시 위치·이동 경로는 수집하지 않습니다. 클라이언트 위치는 조작될 수 있으므로 GPS 판정이 현장 존재나 본인 출근을 완전히 증명하지는 않습니다.

네이티브 앱의 권한 안내·위치 API·안전한 서버 인증과 실제 WebView 검증은 후속 단계입니다. 현재 자동 검증은 API 판정과 웹 흐름 기준입니다.
