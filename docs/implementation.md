# 현재 구현 범위

## 연결 완료

- React·TypeScript·Tailwind 모노레포, 직원/관리자 독립 웹 앱과 Capacitor 프로젝트.
- Fastify + SQLite 영속 DB, 자동 버전 마이그레이션.
- 초기 관리자 로컬 생성, 직원·관리자 초대/활성화/재발급, 로그인/로그아웃, 퇴사자 차단.
- 서버 시각 출퇴근, 같은 요청 키의 중복 방지, 실제 기록 조회·CSV.
- 휴가·외근·출근/퇴근 정정 신청, 타 관리자 승인·반려, 본인 대기 취소.
- 원본·정정 값 분리, 낡은 정정 승인 거부, 누락 퇴근 정정 후 다음 날 근무 가능.
- 실제 등록 직원·승인 일정 기반 상태 공유, 일반 직원에게 타인의 이메일·출근 시각 비공개.
- 휴데이터스 주소, 관리자 GPS 설정, 출퇴근 때만 측정, 서버 판정, 외근 예외.
- 사용자 권한·Origin·CSRF·로그인 제한·만료·접근 회수 검증.

## 실제 운영 전 남은 작업

1. 실제 사무동에서 중심 좌표·반경을 확인하고 GPS 활성화. API는 좌표를 추정해 넣지 않음.
2. 회사 관리 계정·HTTPS 호스팅·영속 볼륨·리버스 프록시·모니터링 구성.
3. 비밀번호 재설정·관리자 MFA·보관/파기 정책·실제 백업 복구 훈련.
4. iOS/Android의 서버 인증·보안 저장소·위치 권한 어댑터·실기기 검증·앱 서명.
5. 반차 인정시간·기초 잔여 연차·휴가 승인 취소·사용 잔액.
6. 관리자 전사 월별 근태표·집계·마감·재개방·자료 추출 감사 이력.
7. 푸시·외근의 시간 구간·휴게 정정·개인 외출·자정 넘는 근무의 상세 처리.
8. 소수 직원 파일럿과 기존 기록 병행, 한 번의 월별 마감 검증.

현재 휴가 승인은 일정만 반영합니다. 승인 즉시 연차 차감이나 근무 인정시간을 산출한다고 표시하지 않습니다. 관리자 대시보드의 최근 근무표도 본인 자료이며 전사 월별 집계가 아닙니다.

## 회사에서 결정할 정책

- 출근 마감·코어타임·근무 요일·공휴일.
- 08:00 이전 근무 인정. 현재 원본 보존과 확인 필요 표시만 제공.
- 오전/오후 반차 시간, 시간 휴가, 기초 연차 잔액과 관리 담당자.
- 점심 중 업무·개인 외출·외근 직출/직퇴·마감·재개방·보관기간.

본인 요청을 처리할 별도 관리자가 필요합니다. 초기 관리자 한 명만 있을 때 본인 신청을 자동 승인하는 우회 기능은 제공하지 않습니다.

## 검증 범위

순수 계산은 점심 중첩·목표 시간·한국 시간대·잘못된 입력을 확인합니다. API는 실제 임시 SQLite DB로 초대·로그인·권한·세션·중복 기록·정정 원본·충돌·GPS·재시작 영속성을 확인합니다. 브라우저는 가상 화면 테스트와 실제 서버 연결 테스트를 분리하고, 두 뷰포트에서 서로 다른 계정의 초대→출퇴근→신청→승인→원본 확인과 비활성화→기존 세션 차단을 검증합니다.

실제 iOS/Android 네이티브 빌드·회사 현장 GPS·운영 배포는 수행하지 않았습니다.
